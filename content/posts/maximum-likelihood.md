Функции потерь в ML не выдуманы из воздуха — большинство из них выводятся из **метода максимального правдоподобия** (MLE). Понимание этой связи превращает «магические формулы» в следствия одного принципа.

## Идея правдоподобия

Пусть данные порождены вероятностной моделью с параметрами `θ`. **Правдоподобие** — это вероятность увидеть именно нашу выборку при данных `θ`:

```
L(θ) = ∏ᵢ p(yᵢ | xᵢ, θ)
```

MLE ищет `θ`, при котором наблюдаемые данные максимально вероятны. Произведение неудобно, поэтому берут логарифм — он превращает произведение в сумму и не меняет точку максимума. Максимизация log-likelihood эквивалентна минимизации **negative log-likelihood (NLL)** — это и есть наша функция потерь.

## MSE из гауссовского шума

Предположим `y = f(x) + ε`, где шум `ε ~ N(0, σ²)`. Тогда

```
p(yᵢ | xᵢ) = (1/√(2πσ²)) · exp( −(yᵢ − f(xᵢ))² / (2σ²) )
```

Берём логарифм произведения по всем объектам:

```
log L = − (1/2σ²) · Σ (yᵢ − f(xᵢ))²  +  const
```

Максимизировать это по параметрам `f` — то же самое, что **минимизировать сумму квадратов ошибок**. Вот и вся MSE: она не аксиома, а следствие предположения о нормальном шуме.

## Log-loss из распределения Бернулли

В бинарной классификации ответ распределён по Бернулли с вероятностью `p = a(x)`:

```
p(y | x) = pʸ · (1 − p)¹⁻ʸ
```

Логарифм даёт `y·log p + (1−y)·log(1−p)`, а NLL — это ровно **log-loss / кросс-энтропия**. Для нескольких классов аналогично получается категориальная кросс-энтропия.

## MAP vs MLE

Если добавить априорное распределение на параметры `p(θ)`, то вместо MLE получаем **MAP** (максимум апостериорной вероятности): максимизируем `L(θ)·p(θ)`. Как мы увидим в теме про регуляризацию, гауссов prior даёт L2-штраф, а лапласов — L1.
