Метод опорных векторов (SVM) — классификатор, который проводит границу не абы как, а с максимальным «запасом» до ближайших объектов.

## Идея максимального зазора

Среди всех разделяющих гиперплоскостей SVM выбирает ту, у которой **зазор (margin)** до ближайших точек классов наибольший. Широкая полоса означает устойчивость: небольшой сдвиг данных не перевернёт классификацию. Объекты, лежащие на границе полосы, — **опорные векторы**; только они определяют решение, остальные не важны.

Прямая задача формулируется так:

```
min ½‖w‖²   при условии   yᵢ(wᵀxᵢ + b) ≥ 1  для всех i
```

Минимизация `‖w‖²` эквивалентна максимизации ширины зазора.

## Мягкий зазор

Реальные данные не разделимы идеально. Вводят **slack-переменные** `ξᵢ ≥ 0`, разрешающие нарушения, и штраф за них с коэффициентом `C`:

```
min ½‖w‖² + C·Σ ξᵢ
```

`C` задаёт компромисс: большое `C` — почти не терпим ошибок (риск переобучения), малое `C` — шире зазор, больше допущенных нарушений.

## Двойственная задача и появление скалярных произведений

Через множители Лагранжа задачу переписывают в **двойственной** форме. В ней данные входят **только через скалярные произведения** `⟨xᵢ, xⱼ⟩`, а не по отдельности:

```
max Σαᵢ − ½ ΣΣ αᵢαⱼ yᵢyⱼ ⟨xᵢ, xⱼ⟩
```

Это и есть ключ к следующему шагу.

## Ядерный трюк и условие Мерсера

Раз данные входят только скалярными произведениями, их можно заменить **ядром** `K(x, x′) = ⟨φ(x), φ(x′)⟩`, где `φ` — отображение в пространство большей размерности. При этом само `φ` вычислять не нужно — достаточно ядра. Так линейный SVM строит нелинейные границы.

Функция может быть ядром не любая: по **условию (теореме) Мерсера** `K` должна быть симметричной и **положительно полуопределённой** — тогда она соответствует какому-то скалярному произведению в некотором пространстве. Популярные ядра: линейное, полиномиальное, RBF (гауссово).
